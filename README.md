 Audiobook Dom Casmurro

Uma aplicação web para reprodução de áudio interativo baseada na obra clássica Dom Casmurro, de Machado de Assis. O projeto permite ouvir os capítulos do livro com controles intuitivos de navegação, ajuste de velocidade e acompanhamento de progresso.

 Funcionalidades

Navegação por Capítulos: Alterne facilmente entre os capítulos da obra.

Controle de Player de Áudio:

Play / Pause.

Avançar ou voltar capítulos rapidamente.

Ajuste de velocidade de reprodução (ex: 1x, 1.5x, 2x).

Interface Responsiva: Adaptada para navegação em dispositivos móveis e desktops.

Exibição do Capítulo Atual: Acompanhamento visual da faixa e capítulo em execução.

 Tecnologias Utilizadas

HTML5: Estruturação dos elementos da página e player de áudio nativo.

CSS3 / FontAwesome: Estilização moderna e ícones de controle de mídia.

JavaScript (Vanilla JS): Manipulação da DOM, gerenciamento de estado do áudio e controle de eventos de reprodução.

 Estrutura do Projeto

audiobook-dom-casmurro/
├── audios/            # Arquivos de áudio dos capítulos
├── images/            # Imagens e capa do projeto
├── index.html         # Estrutura principal da aplicação
├── script.js          # Lógica do áudio e interatividade
└── style.css          # Estilização e layout da interface


 Como Executar o Projeto

Clonar o Repositório:

git clone https://github.com/Vinicius-jafe/audiobook-dom-casmurro.git


Acessar a Pasta do Projeto:

cd audiobook-dom-casmurro


Executar a Aplicação:

Basta abrir o arquivo index.html em qualquer navegador web.

Opcional: Se utilizar o VS Code, pode utilizar a extensão Live Server para rodar localmente com suporte a hot reload.
